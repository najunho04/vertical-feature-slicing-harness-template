# 루프 엔지니어링 설정

목표 점수만 걸면 그 점수만 오른다. **지표당 루프 하나.** 불변 게이트는 쓰기 권한 밖.

## 루프: {이름}

| 항목 | 값 |
|---|---|
| 목표 지표 | {예: p95 응답시간 < 200ms} |
| 측정 명령 | {예: `npm run bench:order-cancel`} |
| 불변 게이트 | `npm run test` (계약 테스트) + `npm run test:e2e` — 하나라도 깨지면 이터레이션 무효 |
| 최대 반복 횟수 | {예: 5} — 도달 시 성공 여부와 무관하게 중단, 사람에게 인계 |
| 스탑 기준 | {목표 도달 / 최대 반복} |
| diff 리뷰 | 점수가 올랐어도 어떻게 올렸는지 본다 |

## 실행 시점
- 슬라이스별 1회 + 통합 후 1회
