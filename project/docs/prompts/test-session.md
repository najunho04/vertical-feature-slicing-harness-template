# 테스트 세션 프롬프트

깨끗한 세션. **구현 코드 접근 없이** 컨텍스트 카드만 보고 계약 테스트를 작성한다. 사람 승인 후 커밋하면 동결된다.

슬라이스마다 이 템플릿에 카드를 붙여 `project-all-docs/prompts/{slice}-test-session.md`로 저장해 두고, 세션에는 그 내용을 붙여넣는다.

```
아래 명세를 보고 계약 테스트를 작성해줘. 3~7개.

- 구현 코드는 열지 말 것. 명세만 보고 작성. (`common/`, `shared/`, 테스트 공용 설정은 읽어도 됨. `feature/` 는 열지 말 것)
- 정상 케이스 + 불변조건 위반 + 권한 위반을 다룰 것.
- 응답 DTO의 필드와 타입을 검증할 것.
- 명세에 없어서 판단이 안 서는 부분은 지어내지 말고 질문으로 남겨줘.
- 저장 위치: backend/test/contract/{slice}/ (백엔드 테스트 프레임워크 사용)
- 이 슬라이스 폴더 밖에는 쓰지 말 것. 작성 후 커밋하지 말고 멈춰서 승인을 기다릴 것.
- 구현이 없으므로 테스트는 실패하는 것이 정상. `SLICE={slice} make test-slice` 로 수집 오류만 없는지 확인할 것.

[컨텍스트 카드]
```
